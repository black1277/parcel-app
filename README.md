## Изучение английского

1. Для устранения привыкания к шрифту - меняйте шрифт перед повторением пройденного
2. Для устранения привыкания к порядку предложений - активируйте опцию "перемешать"
3. Правильно введенный ответ (независимо от регистра) - подсвечивается зеленым
4. Двойной щелчок по предложению - выдает правильный ответ
5. Для сравнения правильного ответа со своим вариантом - наведите мышь на ответ
6. Меняйте местами русские и английские предложения - для изучения перевода в обе стороны
7. Пробелы между словами, в начале и в конце не влияют на правильность ответа
8. Регистр букв не имеет значения
9. Для большинства английских предложений существуют несколько правильных вариантов
10. Если не помните с какого слова начинается ответ - зажмите Ctrl и сделайте клик в поле ответа

## Как пользоваться

- Читаете предложение, переводите, вписываете перевод в правое поле
- Если написали правильно - подсветится зеленым, если неправильно - останется желтым
- Если не помните как правильно - делаете двойной клик по предложению слева - будет заполнено поле справа
- Если в поле справа что-то было до автозаполнения, то при наведении на ответ этот текст будет всплывать, чтобы можно было сравнить свой ответ с правильным
- Когда почувствуете, что уверены в своих ответах - измените шрифт и активируйте опцию "перемешать"
- Обязательно меняйте направление перевода - переключатель "rus-eng"
- Комбинация клавиш Ctrl+Alt+ArrowRight листает вправо, Ctrl+Alt+ArrowLeft - влево
- Комбинация Ctrl+Alt+Space выбирает рандомную страницу. Страницы не повторяются, пока не пройдут полный цикл. Прогресс ненадолго отображается по центру.
- Количество пробелов - не влияет на правильность ответа.
- Если цифра посреди строки на розовом фоне - значит вариантов ответа больше одного.
- Можно использовать свой шрифт для отображения вариантов. Можно задать ссылку на шрифт в googlefonts или загрузить свой файл шрифта с компьютера. Это сохраняется только для текущего сеанса.
- Можно задать свой цвет фона.
- Можно изменять размер шрифта в некоторых пределах.
- Есть поиск по русским и английским словам - в зависимости от переключателя "rus-eng"
- Иногда бывает, что ваш ответ отличается от правильного всего на 1-2 буквы. Тогда можно нажать кнопку Help и увидеть до какой буквы ваш ответ совпадает с шаблоном и попытаться исправить
- Зажатие клавиши Ctrl и клик  по желтому полю добавляет одно слово из ответа (действует только если предыдущие слова набраны правильно)
- Зажатие клавиши Ctrl и клик по зеленому полю - озвучивает ответ (если эта возможность есть на вашем устройстве)

## Разработка

```bash
npm install
npm start          # генерирует src/data/index.js и запускает Parcel на http://localhost:1234
npm run build      # то же + production-сборка в ./public
npm test           # юнит-тесты логики (встроенный node:test)
npm run lint       # ESLint
npm run format     # Prettier
npm run cy:run     # e2e-тесты Cypress (приложение должно быть запущено: npm start)
```

### Как добавить страницу с предложениями

Создайте `src/data/pages/dataN.js` (N — следующий номер) в том же формате, что и соседние файлы:
массив объектов `{ rus, eng, regEng? }`. Индекс `src/data/index.js` собирается автоматически
перед `npm start` / `npm run build`, порядок страниц определяется числом N.

### Структура проекта

```
src/
├─ index.html              разметка страницы
├─ main.js                 точка входа: собирает приложение из модулей
├─ config/constants.js     все константы: ключи localStorage, шрифты, лимиты, тексты
├─ core/                   чистая логика без DOM (покрыта юнит-тестами)
│  ├─ answerChecker.js     проверка ответа, шаблоны, подсказка Help
│  ├─ search.js            поиск по страницам
│  ├─ pagination.js        расчёт ссылок навигации (полной и свёрнутой)
│  ├─ randomPagePicker.js  случайные страницы без повторов
│  ├─ rows.js, shuffle.js, text.js, color.js
├─ services/               работа с внешним миром
│  ├─ storage.js           настройки в localStorage
│  └─ fontService.js       Google Fonts и шрифты из файла
├─ state/appState.js       состояние тренажёра
├─ ui/                     всё, что рисует интерфейс
│  ├─ elements.js          реестр DOM-элементов
│  ├─ shell.js, templates/ каркас страницы
│  └─ views/               отрисовка строк, навигации, прогресса, блокировки
├─ features/               поведение: связывает core, ui и services
│  ├─ trainer/             контроллер тренажёра, строки ответов, горячие клавиши
│  ├─ settings/            тема, цвет фона, размер шрифта, свой шрифт, видимость блоков, сброс
│  ├─ a11y/, clipboard/
├─ data/                   страницы с предложениями (pages/dataN.js) и генерируемый index.js
├─ styles/                 CSS по компонентам; index.css задаёт порядок подключения
└─ assets/                 картинки и иконки
scripts/generate-data-index.mjs   генератор src/data/index.js
tests/unit/                юнит-тесты
cypress/                   e2e-тесты
```
